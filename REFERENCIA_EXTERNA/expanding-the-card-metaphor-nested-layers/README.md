# Expanding The Card Metaphor: Nested Layers

A Pen created on CodePen.

Original URL: [https://codepen.io/andersschmidt/pen/YPVXMw](https://codepen.io/andersschmidt/pen/YPVXMw).

Disclaimer: Tested to work in latest Chrome, no guarantees in other browsers.

I'm currently experimenting with ways to expand the card metaphor that is rapidly gaining interest in today's UI design landscape. In this experiment, I look at how a card could include a nested layer that appears when clicking e.g. "View advanced settings".

This card also includes the basic horizontal rotation to view the back of the card, but the main focus is on the extra layer revealed by clicking "View advanced...".

The idea does not have to be isolated to the card metaphor, but could also be used with dialog windows in general.

# How React Props Work

A Pen created on CodePen.

Original URL: [https://codepen.io/team/codepen/pen/vbVOQE](https://codepen.io/team/codepen/pen/vbVOQE).

Props are a lot like HTML attributes. In this bit of JSX:

```
<Module title="Hello, World!" />
```

The "prop" is `title` and it is passing a value of `Hello, World!` as a string. This is a way of passing data from one place to another.
